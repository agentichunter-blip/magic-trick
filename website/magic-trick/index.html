Game library

Your Game Boy and Game Boy Color games, by cover art instead of a file list. Stop on a game and the cover turns into a looping gameplay clip.

  • Your covers and clips, from the SD card. Included tools convert them.
  • Quick to scroll: tap to step, hold for a five-row list, keep holding to speed up.
  • Folders and a Game Boy / Game Boy Color picker.
Available nowMCU firmware

Cheats and recent games

A gold lamp marks games with Game Genie codes. Press Select on the preview to turn them on. Your ROMs are never modified.

  • Game Genie: build packs for your library with the included tool. How to →
  • Recent: your last 20 games per system.
  • Last-game startup: with no cartridge in, it reopens your last game. Hold B at power-on to skip it.

Not a save state. Last-game startup loads the game's normal save, not the exact moment you left.

New in 1.0 betaFPGA core + MCU firmware

Game Gear

A third system next to Game Boy and Game Boy Color. Sonic 2 and Columns run with correct picture and sound on a real Chromatic. New in 1.0 beta. Game Gear has no save states yet.

  • FPGA core, adapted from MiSTer's Master System core. Not software emulation.
  • Automatic switching: pick a Game Gear game and the Chromatic swaps cores; pick a Game Boy game and it swaps back.
  • Still to test: Game Gear covers, previews and Game Genie. No save states for Game Gear.
New in 1.0 betaFPGA core + MCU firmware

Save states

Save anywhere and jump back to that exact frame. Tested on a real Chromatic with Game Boy and Game Boy Color games, including ten restores in a row. New in 1.0 beta.

  • Full snapshot from the FPGA core: CPU, video, audio, memory and mapper.
  • One slot, cleared on power-off, reset or game change.
  • Shortcuts: Menu + Up saves, hold Menu + Down loads. Controls →
  • Limits: SD games with MBC1 or MBC5. No cartridges or clock games yet.
New in 1.0 betaMCU firmware

Wi-Fi transfers

Join Wi-Fi from the System menu, open the address the Chromatic shows in any browser on your network, enter the 6-digit code, and move games, covers and saves. No cable, no card reader.

  • No app, no account. Nothing leaves your network.
  • Safe: pairing code required, existing files never overwritten.
  • Games pause while Wi-Fi is on. It joins your router; no hotspot mode.
  • Verified byte for byte on a real Chromatic. Long sessions still being tested.

Boot animation

Magic Trick now starts with its own animation. It's built into the firmware, plays without an SD card, and replaces the old two-second pause.

  • 144 frames at 30 fps, confirmed on a real Chromatic.
  • Skippable: press any button. It's skipped when switching systems.
  • Silent. The ESP32 has no audio path.

Game Genie cheats

Build packs for your games once. After that, a lamp shows which games have cheats.

  1. Add cheat packs once. Run the included cheat tool on your game library, then copy the CHEATS folder into the CHROMAGIC folder on your SD card. Cheat pack guide ↗
  2. Look for the lamp next to a game's cover or title in your library:
    Outlined: cheats availableFilled: cheats on for next launch
    No lamp means there's no pack for that game.
  3. Open the cheats. Show the game's preview and press Select. If the scrolling list is open, press A first to reveal the preview.
  4. Pick your cheats. Up/Down to browse, A to turn a cheat on or off, B to go back. The top item turns them all off.
  5. Start the game. Cheats apply the next time it launches, including automatic last-game startup. They can't be switched on in a game that's already running.

Choices are remembered per game. Turning a cheat off doesn't undo anything already written to that game's normal save. GameShark and Pro Action Replay codes aren't supported.

Save states

Game Boy and Game Boy Color games on your SD card. New in 1.0 beta.

  1. Open the menu while playing. Press Menu, go to the System tab, highlight Save States and press A.
  2. Save. Choose Save State. It replaces your one saved snapshot.
  3. Load. Choose Load State. Cancel is selected first so you can't load by accident: move to Load State and press A. B cancels.
ShortcutsTurn Shortcuts on in the same panel. It stays on after restarts. SaveHold Menu + Up, then release both. LoadHold Menu + Down for one second, then release both. This skips the confirmation.

One slot, kept in memory: it's cleared when you power off, reset or switch games. Loading an older state keeps your newer battery save safe in a separate file. Works with SD games that use the MBC1 or MBC5 mapper (most of the library). Physical cartridges, real-time-clock games and Game Gear aren't supported.

If something goes wrong: recovery

If an install or update stops, keep your backup folder and its installation.json. It records how far the installer got.

  • Run the installer again. The FPGA can always be reached over USB, even after an interrupted write, and a rerun rewrites anything incomplete.
  • If the Chromatic isn't detected, unplug it, power-cycle it and reconnect. Don't erase flash or overwrite your only backup.
  • Installer refuses to start, or the screen stays dark? Use Restore backup with mcu-backup.bin from your first install. Copy that folder somewhere safe after installing.
  • Want to go back? Use Uninstall in the app, then ModRetro's official updater for a full return to stock. ModRetro's updater can't reflash a device running Magic Trick 1.0 until you've uninstalled.
  • Still stuck? Open a GitHub issue with installation.json and the log, never the backup itself.

Magic Trick is a modification of CursedToast's ChroMagic, which is based on ModRetro's open-source Chromatic firmware and FPGA design. The FPGA builds on the MiSTer Game Boy core (ported from Gameboy for MiST), with boot ROM sources adapted from SameBoy (MIT). The firmware uses Espressif ESP-IDF and LVGL. Optional cheat packs are compiled from the libretro-database.

About the project

Magic Trick is a free, open-source firmware mod for the ModRetro Chromatic. It turns the handheld's file list into a game library with cover art, looping gameplay previews, Game Genie cheats, a Recent games folder and automatic last-game startup. A desktop installer for Mac, Windows and Linux installs, updates and uninstalls it.

Magic Trick builds on CursedToast's ChroMagic and ModRetro's open-source firmware, and is released under the GPL v3. Version 1.0 beta adds a Game Gear core with sound and automatic core switching, true Game Boy and Game Boy Color save states, Wi-Fi file transfers and a Magic Trick boot animation.
