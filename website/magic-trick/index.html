Available nowMCU firmware

A game library worth browsing.

Magic Trick replaces the plain file list with a Game Boy and Game Boy Color library built around your own cover art. Rest on a game and its cover gives way to a silent, looping gameplay clip, so you can see what you're about to play.

  • Covers and clips from your SD card. Bring your own; the included converters prepare them.
  • Fast navigation. Tap to step through covers, hold for the five-row selector, keep holding to accelerate.
  • Nested folders and a Game Boy / Game Boy Color system picker.
  • Media loads in the background and is cancelled as you scroll, so browsing stays responsive.
Available nowMCU firmware

Cheats, recents and a faster start.

A gold lamp marks games that have Game Genie codes. Press Select on a game's preview to turn codes on, and they apply the next time it starts. Your ROM files are never modified.

  • Game Genie cheats from packs you generate for your own library with the included tool. No cheat database is bundled. How to use them →
  • Recent games: the last 20 games per system, newest first, kept across power cycles.
  • Last-game startup: with no cartridge inserted, the Chromatic reopens the last game you launched. Hold B at power-on to go to your library instead.

Not a save state. Last-game startup reopens the game with its normal saved progress. It does not resume the exact moment you left. True save states are a separate feature, working in development firmware.

Working on hardwareFPGA core + MCU firmware

Game Gear, on a Chromatic.

Game Gear is now a third system beside Game Boy and Game Boy Color. On a real Chromatic, Game Gear games such as Sonic 2 and Columns run with correct picture and sound, and the menu works on top of them. It isn't in a published release yet and needs more testing before anyone else should try it.

  • A real hardware core. Game Gear runs on its own FPGA core, adapted from the open-source MiSTer Master System core, not on software emulation.
  • Switches cores automatically. Pick a Game Gear game and the Chromatic reloads into the Game Gear core and starts it; pick a Game Boy game and it switches back. The original firmware is kept on the device as a recovery copy.
  • Still to verify on device: Game Gear covers and previews, and Game Genie for Game Gear (built and passing automated tests). Game Gear has no save states.
Working on hardwareFPGA core + MCU firmware

True save states.

Freeze a game at any moment and jump back to that exact frame, even mid-level. Saving and restoring has been tested on a real Chromatic with Game Boy and Game Boy Color games, including ten repeated restores in a row. It isn't in a published release yet, and the on-screen menu is still being tested on the device.

  • Captured by the FPGA core itself: CPU, video, audio, memory and cartridge-mapper state, not just the game's own save.
  • One temporary slot, held in memory. It is cleared on power-off, reset or when you change games.
  • Optional shortcuts: Menu + Up to save, hold Menu + Down to load. Full controls →
  • Current limits: SD games using MBC1 or MBC5 only. Cartridges and real-time-clock games aren't supported yet.
Working on hardwareMCU firmware

Wireless file transfers.

Join your home Wi-Fi from the System menu and the Chromatic shows its local address and a 6-digit code. Open that address in any browser on the same network, enter the code, and copy games, covers and saves to and from the SD card. No card reader and no cable needed.

  • A small web page served by the Chromatic itself. No app to install, no cloud account, nothing leaves your network.
  • Careful by default: a pairing code is required, and existing files are never overwritten.
  • Games pause while Wi-Fi is on. Turn it off to play. It joins your router; there's no hotspot mode.
  • Tested on hardware: transfers checked byte-for-byte with SHA-256 on a real Chromatic. Long sessions and weak-signal recovery are still being tested.
Working on hardwareMCU firmware

A boot animation of its own.

Turn the Chromatic on and Magic Trick greets you with its own animation before your library appears. It's built into the firmware itself, so it plays even without an SD card, and it replaces the old two-second startup pause.

  • 144 frames at 30 fps, confirmed playing in full on a real Chromatic.
  • Never in your way: press any button to skip it. It's skipped automatically when switching between Game Boy and Game Gear.
  • Picture only. The Chromatic's ESP32 has no audio path, so the animation is silent.

How to

Cheats and save states, step by step.

Exact controls from the firmware, so you know what to press before you pick it up.

Available nowGame Boy & Game Boy Color SD games

Use Game Genie cheats

Cheats come from packs you build for your own games. Once they're on your SD card, a lamp shows you which games have them.

  1. Add cheat packs once. Run the included cheat tool on your game library, then copy the CHEATS folder into the CHROMAGIC folder on your SD card. Cheat pack guide ↗
  2. Look for the lamp next to a game's cover or title in your library:
    Outlined: cheats availableFilled: cheats on for next launch
    No lamp means there's no pack for that game.
  3. Open the cheats. Show the game's preview and press Select. If the scrolling list is open, press A first to reveal the preview.
  4. Pick your cheats. Up/Down to browse, A to turn a cheat on or off, B to go back. The top item turns them all off.
  5. Start the game. Cheats apply the next time it launches, including automatic last-game startup. They can't be switched on in a game that's already running.

Choices are remembered per game. Turning a cheat off doesn't undo anything already written to that game's normal save. GameShark and Pro Action Replay codes aren't supported.

Working on hardwareDevelopment firmware

Save and load states

For Game Boy and Game Boy Color games on your SD card. Not in a public release yet; these are the controls in the development firmware.

  1. Open the menu while playing. Press Menu, go to the System tab, highlight Save States and press A.
  2. Save. Choose Save State. It replaces your one saved snapshot.
  3. Load. Choose Load State. Cancel is selected first so you can't load by accident: move to Load State and press A. B cancels.
ShortcutsTurn Shortcuts on in the same panel. It stays on after restarts. SaveHold Menu + Up, then release both. LoadHold Menu + Down for one second, then release both. This skips the confirmation.

One slot, kept in memory: it's cleared when you power off, reset or switch games. Loading an older state keeps your newer battery save safe in a separate file. Works with SD games that use the MBC1 or MBC5 mapper (most of the library). Physical cartridges, real-time-clock games and Game Gear aren't supported.

Back up

Back up your SD card yourself, especially saves. Power on the Chromatic and connect it with a data USB cable.

Open the installer

Extract the whole archive and open Magic Trick Installer. Close any other device apps, then select your Chromatic and a private backup folder.

Let it verify

Keep power and USB connected. The app backs up the MCU, then writes and verifies both firmware parts and checks the running versions.

What the installer checks and changes
  • Checks firmware SHA-256 hashes and the connected hardware before writing.
  • Saves and verifies a full 4 MiB private MCU backup, then validates the partition table and application descriptor.
  • Writes and verifies the Magic Trick MCU application, then the ChroMagic FPGA, then checks the running versions before reporting success.
  • Never writes the SD card, bootloader or partition table.
  • The MCU backup does not include FPGA firmware or SD contents. Keep it private.
Drivers and permissions

Windows may need ModRetro's official MRUpdater USB drivers before the programmer can reach the device. Linux may need serial and USB device permissions. The Mac tools are bundled and don't need Homebrew. The app checks access before it writes any firmware.

Known issues and limitations
  • No end-to-end installation on a physical Chromatic has been tested with this installer.
  • The apps are unsigned. macOS Gatekeeper and Windows SmartScreen will warn you before opening them.
  • Compatibility checks are software checks, not a hardware compatibility certification.
  • Sustained preview performance, broad game and save compatibility, and the behaviour of every cheat have not been verified.
  • Game Genie only, on Game Boy and Game Boy Color SD games. GameShark / Pro Action Replay and live toggling aren't supported.
If something goes wrong: recovery

If an install is interrupted, keep your backup and installation.json. An MCU success with an FPGA failure is a partial install, and the app never reports it as a success.

  • If the console still responds, run the installer again.
  • If it no longer responds, stop. Don't erase flash or overwrite your only backup. Open a GitHub issue with your installation.json (not the backup itself).
  • A full return to stock needs matching stock MCU and FPGA firmware through ModRetro's official MRUpdater. An MCU backup alone does not restore the FPGA.

Magic Trick is a modification of CursedToast's ChroMagic, which is based on ModRetro's open-source Chromatic firmware and FPGA design. The FPGA builds on the MiSTer Game Boy core (ported from Gameboy for MiST), with boot ROM sources adapted from SameBoy (MIT). The firmware uses Espressif ESP-IDF and LVGL. Optional cheat packs are compiled from the libretro-database.

About the project

Magic Trick is a free, open-source firmware mod for the ModRetro Chromatic. It turns the handheld's file list into a game library with cover art, looping gameplay previews, Game Genie cheats, a Recent games folder and automatic last-game startup. A desktop installer for Mac, Windows and Linux installs it from stock firmware in one session.

Magic Trick builds on CursedToast's ChroMagic and ModRetro's open-source firmware, and is released under the GPL v3. The 0.2.0 installer is a testing preview. Game Gear support with sound, true save states, Wi-Fi file transfers and a Magic Trick boot animation already run on a real Chromatic in development firmware and are not yet publicly released.
