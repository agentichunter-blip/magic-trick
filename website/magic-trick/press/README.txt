Magic Trick press kit
=====================

Magic Trick is a free, open-source firmware mod for the ModRetro Chromatic. It turns the handheld's file list into a game library with cover art, looping gameplay previews, Game Genie cheats, a Recent games folder and automatic last-game startup. A desktop installer for Mac, Windows and Linux installs it from stock firmware in one session.

Status (Nov 2026): Installer 0.2.0 is a TESTING PREVIEW (firmware art31). Game Gear support with picture and sound, automatic Game Boy/Game Gear core switching, true save states (GB/GBC), Wi-Fi file transfers and the Magic Trick boot animation RUN ON A REAL CHROMATIC IN DEVELOPMENT FIRMWARE but are NOT in any published release yet.
