# Prebuilt releases

Download the Magic Trick Installer for Mac, Windows or Linux from [GitHub Releases](https://github.com/agentichunter-blip/magic-trick/releases). Firmware is bundled with the installer; see the [installer guide](../installer/README.md) before you start.

No private flash dumps, saves, games, media, or local build logs are distributed.

Magic Trick is free forever. If it made your Chromatic better, [support my work](https://ko-fi.com/ryansag).
